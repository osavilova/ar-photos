# AR-фото

Кожне фото — окрема папка з власною адресою:
`https://osavilova.github.io/ar-photos/<назва-папки>/`

Спільний код сторінки лежить у `shared/` (`ar-photo.js`, `ar-photo.css`).

## Як додати нове фото

1. Скопіюйте папку `sasha-23.10.26-2y5m` під нову назву (латиниця, цифри, `-`, `.`; без імен людей).
2. Замініть у ній файли:
   - `target.mind` — мішень, скомпільована з PNG-макета без змін
     (MindAR 1.2.5, напр. https://hiukim.github.io/mind-ar-js-doc/tools/compile);
   - `video.mp4` — H.264 + AAC, до ~25 МБ;
   - `overlay.png` — (необов'язково) прозорий шар зі стрічками/QR над відео;
     якщо його немає — видаліть рядок `overlay` у `index.html`.
3. У `index.html` нової папки оновіть `layout` (розмір PNG-макета в px)
   і `photo` (x, y, ширина, висота області фото на макеті в px).
   `bleed` — на скільки px відео виходить за краї фото (60 ≈ 2 мм на 10-см друці),
   щоб не було видно краю надрукованого фото.
4. Приберіть метадані: `python3 -I tools/strip-metadata.py <папка>/overlay.png <папка>/video.mp4`.
5. Закомітьте й запуште — сторінка з'явиться за 1–2 хв.
